# Earth texture credits

Retrieved 14 October 2026. All textures are bundled locally; the application does not request them from a CDN at runtime.

| Local asset | Resolution | Source |
| --- | --- | --- |
| `assets/day.jpg` | 4096 × 2048 | [three-globe Earth Blue Marble example texture](https://github.com/vasturiano/three-globe/blob/master/example/img/earth-blue-marble.jpg) |
| `assets/night.jpg` | 4096 × 2048 | [three-globe Earth night example texture](https://github.com/vasturiano/three-globe/blob/master/example/img/earth-night.jpg) |
| `assets/clouds.png` | 4096 × 2048, RGBA | [three-globe cloud example texture](https://github.com/vasturiano/three-globe/blob/master/example/clouds/clouds.png) |

The day texture depicts recognizable terrestrial geography in an equirectangular Blue Marble composite. These images are static visual reference textures, not current satellite imagery or live weather. The day texture includes ocean bathymetry as a visual aid.

The [three-globe clouds example](https://github.com/vasturiano/three-globe/blob/master/example/clouds/index.html) credits the cloud texture to [Bjørn Sandvik's WebGL Earth experiment](https://github.com/turban/webgl-earth). Its alpha channel is preserved. The downloaded images are unmodified.
